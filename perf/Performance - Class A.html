V-SPEEDS

TAKEOFF V-SPEEDS
VEF Engine Failure speed — assumed engine failure point
V1 Decision speed — last moment to abort takeoff
VR Rotation speed — pull back on yoke
VLOF Lift-off speed — wheels leave ground
V2 Takeoff safety speed — maintained to accel alt
VFTO Final takeoff speed — end of segment 3
V-SPEED REQUIREMENTS
Speed Requirement
V2MIN ≥ 1.13 VSR (2/3 eng) or 1.08 (4+ eng)
≥ 1.10 VMCA
VR ≥ 1.05 VMCA
≥ V1
VFTO ≥ 1.18 VSR
+ min climb gradient
VREF ≥ 1.23 VSR0
V2MIN LIMITING FACTORS

VSR (Stall) Limited When:

✓ High density altitude (thin air)
✓ High aircraft weight
✓ Stall speed is high, VMCA drops

VMCA (Control) Limited When:

✓ Low density altitude (dense air)
✓ Low aircraft weight
✓ More thrust = more asymmetry = higher VMCA
"Heavy and High = Stall wins" | "Light and Low = Control wins"

TOR / TOD / ASD

RUNWAY DISTANCES AVAILABLE
Distance Definition
TORA Takeoff Run Available (runway only)
TODA TORA + Clearway
ASDA TORA + Stopway
TOR DEFINITION

Take-Off Run = Distance from brake release to midpoint between VLOF and 35 ft

Example: VLOF at 400m, 35ft at 700m
TOR = (400 + 700) / 2 = 550m
TOR = midpoint | TOD = all the way to 35 ft
ASD CALCULATION (ENGINE FAILURE CASE)
Piece 1: 0 → VEF (AEO) + Piece 2: VEF → V1 (OEI) + Piece 3: V1 → Stop + Piece 4: 2 sec at V1
VEF to V1 = 2 seconds
This is RECOGNITION time (before V1), not reaction time after!
"VEF to V1 = 2 seconds to say WTF"
Engine fails → brain catches up → decide at V1
CLEARWAY vs STOPWAY EFFECTS
Addition FLLTOM OLTOM V1
Clearway ↑ Increases No change ↓ Decreases
Stopway ↑ Increases No change ↑ Increases
Clearway = more room to FLY (field length benefit only)
Stopway = more room to STOP (abort benefit)
IMPROVED V2 PROCEDURE

Used when OBSTACLE LIMITED

✓ Higher V2 = more speed
✓ Shallower initial climb BUT better gradient after
✓ Increases obstacle-limited TOM
✗ Does NOT increase field-length limited TOM

DERATED vs FLEX THRUST

KEY DIFFERENCES
Feature DERATED FLEX
Type Certified engine rating Assumed temperature method
TOGA Available? ❌ NO — locked out ✅ YES — always available
VMCG / VMCA ↓ REDUCED (recalculated) UNCHANGED (based on full thrust)
Contaminated Runway? ✅ ALLOWED ❌ NOT ALLOWED
Dry / Wet Runway? ✅ Allowed ✅ Allowed
WHY DERATE ON CONTAMINATED?

With derate, VMCG is based on reduced thrust — you can't accidentally go TOGA and lose control.

With flex, you could slam TOGA at any moment, putting you below VMCG for that thrust level = danger!

Derated = "locked" thrust → lower VMC → safe on contaminated
Flex = "unlocked" TOGA → VMC unchanged → NO contaminated
COST INDEX
CI = Time Cost / Fuel Cost
CI Priority Speed
CI = 0 Fuel only MRC (slowest)
CI = MAX Time only VMO/MMO (fastest)
CI = 0 → "Zero rush" → Max range
CI = MAX → "Zero budget" → Max speed
