GAS - General Adaptation Syndrome

Hans Selye's model of body's response to stressors

1

Alarm

Fight-or-flight • Adrenaline released • ↑HR, ↑BP

2

Resistance

Cortisol released • Fats→Sugar • Sustained energy

3

Exhaustion

Resources depleted • Chronic stress damage • Breakdown

⚠ EXAM: Cortisol = Resistance phase (not Alarm!)
📖

Key Definitions

Stress Body's response to demands placed upon it
Arousal Physiological readiness (CNS activation) — PHYSICAL
Alertness Mental readiness to respond — MENTAL
Vigilance Sustained attention over time (monitoring)
⚠ TRAP: Arousal (physical) ≠ Alertness (mental)
📊

Stressor Categories

Type Source Examples
Environmental Physical surroundings Noise, vibration, temp, hypoxia
Physiological Inside body Fatigue, hunger, illness
Psycho-social Mind/life Financial worry, relationships
⚠ EXAM: Engine noise = Environmental (measurable). Work overload = Psychological (mental)
📈

Yerkes-Dodson Curve & Workload

Underload (Left Side)

Boredom, hypovigilance, complacency. Familiar + easy = mistakes. "Familiarity breeds contempt"

Overload (Right Side)

Past breaking point → performance collapses, tunnel vision, auditory exclusion

💡 MEMORY
Breaking Point = threshold beyond which further stress → overload
🧠

Information Processing

Type Direction Description
Top-Down Brain → Senses Expectations shape perception, disguises inconsistencies
Bottom-Up Senses → Brain Raw facts drive perception, data-based
⚠ DANGER: Top-down = see what you EXPECT, not what's there

Learning Techniques

Type Mechanism Example
Classical Stimulus association (Pavlov) Fire bell → automatic response
Operant Consequences shape behavior (Skinner) Good landing → praise → repeat
Cognitive Thinking, analyzing, understanding Understanding WHY procedure works
Repetition Repeated practice Drilling checklists
⚠ EXAM: Operant = reinforcement. Classical = association (no reward needed)

Anderson's Skill Acquisition

COGNITIVE → ASSOCIATIVE → AUTOMATIC
C

Cognitive

Thinking hard, slow, effortful, full attention required

A

Associative

Linking actions, getting smoother, less errors

A

Automatic

Effortless, fast, can multitask, minimal attention

💡 MEMORY
CAA = Cognitive → Associative → Automatic (like Civil Aviation Authority!)

Action Slip

Environmental Capture

Regression vs Reversion

Regression

Goes back to: Old trained habits

Example: Airbus pilot reverts to old Boeing procedures under stress

Reversion

Goes back to: Raw instinct (untrained)

Example: Pulling back in stall instead of pushing forward

💡 MEMORY
Regression = previous training | Reversion = primitive instincts 🦧

Coping Strategies

Action Coping

When: Problem CAN be fixed

What: Take action to solve it

Cognitive Coping

When: Problem CANNOT be changed

What: Change how you think/feel about it

⚠ KEY: Can fix it → Action | Can't fix it → Cognitive
🔄

Psychosomatic Response

Psycho (mind) + Somatic (body) = Mental state causes physical response

STRESS (mind) → HORMONES (body)

Examples: Stress → sweating, trembling, ↑HR, adrenaline release

🎲

Decision Making

Bad Decision

Wrong choice from available options (WHAT was decided)

Inappropriate Decision

Wrong timing, context, or authority (WHEN/HOW/WHO decided)

💡 DECIDE MODEL
Detect → Estimate → Choose → Identify → Do → Evaluate
🧀

Active vs Latent Failures

Active Failure

Who: Frontline (pilot, controller)

When: Immediate effect NOW

Ex: Pilot sets wrong altitude

Latent Failure

Who: Management, organization

When: Hidden, dormant, delayed

Ex: Cost cuts in training dept

💡 SWISS CHEESE
Latent = holes already in cheese | Active = lines up holes → accident
💾

Long-Term Memory
