01
Gradient (%)
Gradient (%) = Height (ft) Distance (NM) ÷ 100
or equivalently: (Height ÷ Distance) × 100 when both in same unit
This gives a percentage gradient, NOT an angle in degrees.
To convert gradient to degrees: Gradient (ft/NM) ÷ 100 = Angle (°)
To convert degrees to gradient: Angle (°) × 100 = Gradient (ft/NM)
02
Rate of Descent
ROD (ft/min) = GS (kt) × Gradient (ft/NM) 60
GS = TAS ± wind component (+ tailwind, − headwind)
Rearranged: GS = (ROD × 60) ÷ Gradient
Rearranged: Gradient = (ROD × 60) ÷ GS
Use with gradient in ft/NM, not percentage

03
1-in-60 Rule
Angle (°) = Offset Distance × 60
Cross-Track Error: XTE (NM) = (Angle° × Distance NM) ÷ 60

Distance from angle: Distance = (Height ÷ Angle°) × 60
↳ Convert height to NM first (÷ 6080)

Both offset & distance must be in the same unit
✊
FIST RULE (SLANT HEIGHT TECHNIQUE)
One clenched fist at arm's length ≈ 10° angular elevation
Half fist ≈ 5°

Use with 1-in-60 or trig to estimate distance to ground features:
Distance = Height ÷ tan(angle) → convert ft to NM (÷ 6080)
▸ WORKED EXAMPLE — ILS ROD
Airspeed 110 kt, tailwind 15 kt, ILS glide path 3.5°. Find the ROD.
  • GS = 110 + 15 = 125 kt
  • Gradient = 3.5° × 100 = 350 ft/NM
  • ROD = 125 × 350 ÷ 60 = 730 ft/min ✓
▸ WORKED EXAMPLE — DISTANCE TO DESCEND
Descending from 10,000 ft to 2,000 ft on a 3° glide path. Find the distance.
  • Height = 10,000 − 2,000 = 8,000 ft
  • 3° glide = 300 ft/NM
  • Distance = 8,000 ÷ 300 = 26.7 NM ≈ 26 NM ✓
▸ WORKED EXAMPLE — CROSS-TRACK ERROR
Planned track 241° from VOR. At 24 NM DME, aircraft is on radial 247°. Find XTE.
  • Angle off = 247° − 241° = 6°
  • XTE = (6 × 24) ÷ 60 = 2.4 NM ✓
